# Domain Context

## Local Day

A calendar day interpreted in the user's local timezone. It determines which time entries are loaded and where timestamps appear on the daily view.

## Daily Timeline

The selected Local Day projected into visible activity segments and elapsed time totals. An ongoing category may extend visually to the end of the current Local Day as a faded projection, while totals count only elapsed time.

## Guest

A shared public demo identity whose time history and categories are visible and editable by any visitor using the guest option.
